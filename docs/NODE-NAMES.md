# Node names: the row name decides (22 Nov, #1061)

Before any node `name` override is dropped (I2) the row must carry the right name, because the page shows the row name. The 746 "nearest" nodes sit on 282 rows, in three groups:

1. **Rename the row (56 rows, 263 nodes).** One other name is used by at least 60% of the nodes. Proposed: the row takes that name. The owner reads this list; a row stays as it is when the owner strikes it. A row name is a common name of the species that the page article supports, never a spelling or a local name (#1038).
2. **Group rows (13 rows, 212 nodes).** The nodes name local groups ("Puna bunchgrasses", "Reef algae"). The row gets a plain group name and the local wording moves into the node `desc`.
3. **Spelling or regional variants (213 rows, 271 nodes).** The row name stands and the node name is dropped.
